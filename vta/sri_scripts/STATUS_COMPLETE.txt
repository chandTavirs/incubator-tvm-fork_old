🔧 CUSTOMIZATION:

To add/modify tasks, edit create_explicit_tasks() function:

    def create_explicit_tasks(target):
        tasks = []

        # Example: Add dense task for (1, 1024) → (10, 1024)
        args = (('TENSOR', (1, 1024), 'float32'),
                ('TENSOR', (10, 1024), 'float32'),
                None, 'float32')
        tasks.append(autotvm.task.create(
            'dense_pack.x86', args=args, target=target))

        return tasks
