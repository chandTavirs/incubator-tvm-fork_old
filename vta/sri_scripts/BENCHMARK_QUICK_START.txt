🔍 WHAT IT DOES:

For each model in arch_config:
  1. Filter out unsupported patterns (same as extract_workloads_chunked.py)
  2. Load model from OFA checkpoint
  3. Convert PyTorch → Relay
  4. Quantize and graph pack for VTA
  5. Compile with schedule logs
  6. Upload to VTA device
  7. Create runtime and load parameters
  8. Run timer() with number=4, repeat=3
  9. Calculate mean and std execution time
  10. Save results to JSONL and CSV
